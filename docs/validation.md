## 运行方法

```sh
bash scripts/dev.sh check
# 微信工具开启自动化端口 9421 后
pnpm e2e
pnpm theme-check
```

E2E 仅供本机 Mock，重置模拟权益并添加测试读数。不要对真实账号运行。`ANXIN_WS` 可指定 E2E 和 smoke 连接的自动化地址。
